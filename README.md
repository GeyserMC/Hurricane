# Hurricane
This plugin provides various workarounds for Geyser players that modify the server in order to achieve better playability.

Issues with each workaround are listed in the plugin's config. 

**Please take your time to read them as the workarounds in this plugin can be used for exploitative purposes.**

## Usage
You can download Hurricane-Spigot using this link: https://download.geysermc.org/v2/projects/hurricane/versions/latest/builds/latest/downloads/spigot

## Features
- Fixes bamboo and dripstone collision for Geyser players by setting them to no server-side collision.

## Compatibility
Hurricane-Spigot currently supports Minecraft: Java Edition 1.14.x through 26.2.
